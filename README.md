# 🏭 Automated Sorting Cell

## About
Industrial automation project simulating a complete sorted cell for metal and plastic parts. Developed as a portfolio project demonstrating mechatronics and industrial automation skills.

## How It Works
Parts are emitted onto a conveyor belt and pass through inductive and capacitive sensors:
- **Metal parts** → detected by both sensors → continue straight → metal box
- **Plastic parts** → detected only by capacitive sensor → pneumatic actuator pushes to plastic box

Each box holds **5 parts**. When full, the box conveyor automatically advances, waits for a new box, then resumes.

## Features
- PLC logic programming (Ladder / Control I/O)
- Inductive and capacitive sensor detection
- Pneumatic actuator control
- Automatic box counting and exchange
- Conveyor pause during box change and plastic ejection
- Emergency stop system
- CAD design (parts, structure and cell layout)
- Technical documentation
